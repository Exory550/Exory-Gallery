# ExoryGallery

A feature-rich Android gallery application developed by **exory550**.

## Features

- Gallery with photo and video browsing
- Album management
- PIN-protected encrypted Vault
- Map view for geotagged media
- Full-text media search
- EXIF metadata viewer and stripper
- Duplicate and large file cleanup
- Image format converter
- Storage statistics
- Light/Dark theme

## Tech Stack

- Kotlin + Jetpack Compose
- MVVM + Clean Architecture
- Room Database
- Hilt Dependency Injection
- DataStore Preferences
- Coil for image loading
- ExoPlayer for video
- Google Maps Compose
- Media3
- GitHub Actions CI/CD

## Build

```bash
./gradlew assembleDebug
```
